# 危害分析（人オーナー）

AIはこのファイルの結論を勝手に緩めない。新しい危害は人が追記してから実装する。

| ID | 危害 | Copilot の扱い |
|----|------|----------------|
| H1 | 情報過多で前方注意が落ちる | 過負荷時は HUD 抑制・案内保留 |
| H2 | 生成文が運転操作を指示する | LLM は文言のみ。車両指令JSONは拒否 |
| H3 | 誤ってブレーキ等を出す | 許可リスト外は実行しない。CIで禁則語 |
| H4 | クラウド送信による遅延・漏洩 | 過負荷時は LLM を呼ばない。原則オフライン |

ASIL 部品にしない。対象は QM の HMI 支援。運動制御の代替ではない。
